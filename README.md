## Gestión de Paquetes y Scripts de Ejecución

### Dependencias Instaladas
* **`express`**: Framework principal para gestionar la arquitectura backend, enrutamiento y procesamiento de peticiones HTTP.
* **`dotenv`**: Módulo para cargar variables de entorno desde un archivo `.env`, protegiendo la configuración sensible de la aplicación.
* **`nodemon`** *(devDependency)*: Herramienta de desarrollo que reinicia automáticamente el servidor Node.js ante cambios en los archivos del código fuente.
